# BCS অধ্যয়ন — প্রোটোটাইপ

একটি স্তরভিত্তিক BCS প্রস্তুতি অ্যাপের ইন্টারফেস মডেল।

## চালানোর নিয়ম

1. এই রেপোজিটরিতে `index.html` খুলুন।
2. অথবা যেকোনো static server চালান:

```bash
python3 -m http.server 8080
```

তারপর ব্রাউজারে `http://localhost:8080` খুলুন।

## মডেল ফিচার

- বিষয় → অধ্যায় → বিস্তারিত পাঠ নেভিগেশন
- দিন, সেপিয়া ও নাইট থিম
- ফন্ট সাইজ নিয়ন্ত্রণ
- পাঠ খোঁজা
- বুকমার্ক সংরক্ষণ
- প্রিন্ট/PDF
- মোবাইল-রেসপন্সিভ পাতা
